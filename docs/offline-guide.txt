MSX CF-2000 Studio 0.1.0 オフラインガイド
==========================================

この版は基本実装のプレビューです。CF-2000 実機、Windows XP SP3、物理テープ、
openMSX 連携の受入試験はまだ行っていません。重要なデータは必ず別の場所にも
保存してください。

1. 同梱物
--------
  msxstudio.exe             Win32 GUI
  msxtool.exe               コマンドライン
  docs\offline-guide.txt    このファイル
  docs\analysis.md          実装方針と未実装範囲
  docs\formats.md           BASIC / CAS / FSK 形式
  docs\verification.md      受入試験との対応
  examples\HELLO.bas        サンプル

openMSX、MSX の ROM、Windows は同梱していません。

2. インストール（Windows XP SP3 以降）
--------------------------------------
  1) setup をダブルクリックします。
  2) 管理者権限は不要です。ユーザーごとの
     「Local Settings\Application Data\MSXCF2000Studio」に導入されます。
  3) スタートメニューの「MSX CF-2000 Studio」から起動します。
  4) アンインストールしても、ユーザーが保存した .bas / .cas / .wav は削除されません。

3. 編集と検証
-------------
  1) 「ファイル > 開く」で .bas（UTF-8）を開きます。行番号が必要です。
  2) F5 で検証します。ログに行・桁付きでエラー、警告、空き容量が出ます。
     プログラム領域は 0x8000 開始、FRE(0)=12431 バイトを基準にしています。
  3) Ctrl+Space で補完、Ctrl+Z で Undo、Ctrl+S で保存（UTF-8、BOM なし）。

4. テープ設定
-------------
  「テープ > テープ設定」で MSX ファイル名（6 バイト以内）と
  1200 / 2400 baud を指定します。名前は切り詰めません。
  日本語の文字は 1 文字 2 バイトとして数えます。

5. CF-2000 への送信（PC → 実機）
--------------------------------
  1) MSX 用カセットケーブルで PC の音声出力を CF-2000 の CMT 入力へ接続します。
     標準 DIN では CMTOUT（MSX 側）が PC 入力、CMTIN が PC 出力です。結線を確認してください。
  2) CF-2000 で CLOAD"名前" と入力して待機させます。
  3) PC 側で F6（または「実行・デバッグ > CF-2000 へ送信」）を押します。
  4) 再生が終わったら、実機で LIST / RUN を確認します。
     「送信完了」は受信成功を意味しません。
  5) 失敗する場合は 1200 baud に落とし、PC の音量を下げて再試行します。

6. 録音（実機 → PC）
--------------------
  1) CF-2000 の CSAVE"名前",1 または ,2 を実行します。
  2) PC 側で F7（録音）を押し、保存先 .wav を指定します。
  3) 入力メーターが -18～-6 dBFS になるよう調整します。-3 dBFS 以上は過大です。
     CLIP 表示が出たら、アナログ段で減衰してください（デジタル正規化では直りません）。
  4) 録音停止後、WAV は 48 kHz / 16 bit / モノラルで保存されます。
     バッファ欠落が出た WAV は正常完了として扱わないでください。

7. WAV の復号
-------------
  1) F8（または「テープ > WAV を復号」）で WAV を選びます。
  2) リーダー、1200/2400、ブロック、フレームエラーがログに出ます。
  3) CAS と BASIC（BASIC ファイルの場合）の保存先を指定します。
  4) 復号結果は「構造を認識した」状態です。既知データとの照合はまだ行いません。

8. コマンドライン
-----------------
  msxtool validate HELLO.bas
  msxtool bas2cas HELLO.bas -o HELLO.cas --name HELLO
  msxtool bas2wav HELLO.bas -o HELLO.wav --name HELLO --baud 2400
  msxtool cas2wav HELLO.cas -o HELLO.wav --baud 2400
  msxtool wav2cas REC.wav -o REC.cas
  msxtool wav2bas REC.wav -o REC.bas
  msxtool casinfo HELLO.cas
  msxtool selftest

9. 困ったとき
-------------
  * 送信しても CLOAD しない
    - ケーブルの MIC/EAR と CMTIN/CMTOUT の向きを確認する。
    - 音量を下げる。マイクブースト、AGC、ノイズ抑制、再生監視を無効にする。
    - 1200 baud で試す。まず短いプログラムで確認する。
  * 録音レベルが動かない
    - 「テープ > テープ設定」の入力機器を確認する。
    - 「テープ > Windows の録音ミキサーを開く」で録音入力を確認する。
  * 復号でリーダー未検出
    - WAV が 48 kHz / 16 bit PCM か確認する。
    - 録音開始が遅れてリーダーが欠けていないか確認する。
    - 手動指定: msxtool wav2cas REC.wav -o REC.cas --baud 1200
  * 漢字がエラーになる
    - CF-2000 の文字表に漢字はありません。ひらがな・半角カナ・GRAPH 文字を使います。
  * 日本語が表示されない（XP のメモ帳）
    - 同梱の .md は UTF-8 です。この .txt は BOM 付き UTF-8 です。

10. データの場所
----------------
  設定: HKEY_CURRENT_USER\Software\MSXCF2000Studio
  録音・CAS・BASIC: 保存時に指定した場所（インストール先ではありません）
  アンインストール: インストール先のプログラムと docs のみ削除します。

11. 注意
--------

  * MSX は MSX ライセンス会社の商標です。
