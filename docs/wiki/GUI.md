# GUI の使い方

`msxstudio.exe` を起動し、`.bas` を開いて編集します。

## ショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` | 新規 / 開く / 保存 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Ctrl+Space` | 補完（入力中も自動表示） |
| `F5` | 検証（行・桁付きの診断、空き容量） |
| `F6` | CF-2000 へ送信 |
| `F7` | 録音 |
| `F8` | WAV を復号 |

## 入力支援

- 入力中に候補を自動表示します（`Ctrl+Space` でも呼び出せます）。
- 文脈で候補を切り替えます。
  - 行頭: 命令（`PRINT`, `GOTO`, ...）
  - 式の中: 関数（`ABS`, `MID$`, ...）と変数
  - `GOTO` / `GOSUB` / `THEN` / `ELSE` の後: 行番号
- `↑` `↓` で選択、`Enter` / `Tab` で確定、`Esc` で取消。
- ステータスバーに **行:桁** と **引数ヒント**（例: `PRINT [式][;|,]...`）を表示します。
- 色分け: 命令（太字）・関数・変数・演算子・区切り・数値・文字列・コメント・`DATA`。

## 送信（F6）

1. 「テープ > テープ設定」でファイル名・ボーレート・送信音量を確認します。
2. PC の音声出力を CF-2000 のカセット入力（MIC/EAR）へ接続します。
3. `F6` で FSK を再生します。

再生が終わっても**実機の受信成功を意味しません**。CF-2000 側で
`CLOAD` → `LIST` / `RUN` を確認してください。

## 録音（F7）

- 48 kHz / 16 bit / モノラル WAV へストリーム書き込みします。
- 「テープ > 入力レベル監視」でピーク、ホールド、CLIP を確認できます。
- 録音の原音 WAV は**無加工**で保存します。

## テープ設定

| 項目 | 説明 |
| --- | --- |
| MSX ファイル名 | 6 バイト以内。超過はエラーで、切り詰めません |
| 入力機器 | 録音に使うデバイス |
| ボーレート | 1200（標準） / 2400（高速） |
| 送信音量 | 1～100%（100% = 約 -7 dBFS）。「自動」で 100% |
| 録音後に復号用の正規化コピーを作る | 既定 ON |

## 録音の正規化コピー

録音終了後、`<名前>.normalized.wav` を自動生成します。

- 目標ピーク: -6 dBFS
- 最大ゲイン: +12 dB
- 既存ファイルがある場合は `-1`, `-2` を付けて上書きを避けます
- 原音 WAV は変更しません

ログに「ピーク -12.3 dBFS → -6.0 dBFS（ゲイン +6.3 dB、原音は無加工で保持）」のように
表示されます。復号（F8）では正規化コピーを選ぶと安定します。

## 復号（F8）

WAV を選ぶと CAS と BASIC を取り出します。ステレオ WAV は第 1 チャンネルを使います。
