# 実機 ROM のダンプ

CF-2000 の ROM は基板直付けですが、**半田を剥がさず**カセット経由で吸い出せます。
MSX BASIC の `BSAVE` はメモリを読むだけなので、ROM 空間も保存できます。

## 1. 実機で保存する

CF-2000 のカセット出力を PC の録音入力へ接続し、BASIC で 4 回保存します。

```basic
BSAVE"ROM0",&H0000,&H2000
BSAVE"ROM1",&H2000,&H2000
BSAVE"ROM2",&H4000,&H2000
BSAVE"ROM3",&H6000,&H2000
```

- 8 KB ずつ、**別々の WAV** に録音してください。
- 1 ブロック約 70 秒 + リーダーです。
- カセット出力はレベルが小さいため、PC 側はマイク入力（プラグインパワー OFF）が無難です。
- 録音レベルは小さめから始め、波形が潰れていないことを確認します。

## 2. 変換する

```bat
scripts\dump-cf2000-rom.bat ROM0.wav ROM1.wav ROM2.wav ROM3.wav
```

スクリプトは次を行います。

1. 各 WAV の正規化コピーを作る（原音は無加工）
2. `wav2cas` → `cas2bin` で 8 KB を取り出す
3. 4 つを連結して `cf2000.rom`（32,768 バイト）を作る
4. SHA1 を表示する

`casinfo` の「宣言長を超えるデータがあります」は、テープブロック末尾の
**チェックサム 1 バイト**によるもので異常ではありません。

失敗したブロックだけ録音し直して、同じコマンドを再実行してください。

## 3. 確認する

openMSX の `National_CF-2000.xml` には ROM の `sha1sum` が書かれています。
表示された SHA1 と一致すれば、正規の CF-2000 ROM です。

XML の `<rom>` 定義が 16 KB × 2 を要求する場合は、32 KB を前半・後半に分割し、
`sha1sum` を自分のダンプの値に合わせます。

## 注意

- ROM は同梱していません。
- 自分が所有する実機からの私的利用目的のダンプは問題ありませんが、**公開・配布はできません**。
