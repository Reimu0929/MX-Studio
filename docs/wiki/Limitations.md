# 制限と未検証項目

## 未検証

- Windows XP SP3 実機での起動・動作（受入試験 XP-01）
- CF-2000 実機での送受信（物理テープ）
- openMSX 0.12.0 との連携
- 音声入力の機器選択と録音ミキサーの実機ドライバーでの確認

## 未実装

- openMSX 連携（行ブレークポイント、変数表示）
- インストーラー（Inno Setup スクリプトはあるがビルド未実施）

## 仕様上の制限

- アプリの復号はステレオ WAV の第 1 チャンネルのみ（CLI は `--channel` 対応）。
- 漢字は CF-2000 の文字コードにないため、コンパイル時にエラー（`?` 置換なし）。
- 全角英数記号は半角へ正規化（例: `！` → `!`）。
- 送信中の進捗は再生位置のみ。実機の受信状態は表示しません。
- CAS/WAV の「構造を認識」と「既知データとの照合済み」は区別しますが、照合機能は未実装。
- FSK の往復は自作波形と自作復調によるもので、規格適合の証明ではありません。

## 法的事項

- MSX の ROM は同梱していません。
- 自分が所有する実機からの私的利用目的のダンプは問題ありませんが、公開・配布はできません。
