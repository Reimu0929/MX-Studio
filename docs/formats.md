# MSX CF-2000 テープ・BASIC 形式メモ

実装で使っている値と、その根拠を記録します。断りがない限り 48,000 Hz /
16 bit / モノラル PCM です。

## 1. トークン化 BASIC（メモリ上）

```
+0  次の行アドレス (LE 16 bit)
+2  行番号 (LE 16 bit、0～65529)
+4  トークン列
末尾 0x00
...
プログラム終端: 00 00
```

- ディスク用 `.bas`（トークン化）は先頭に `0xFF` を 1 バイト置く。
- CSAVE のテープ本体には `0xFF` を置かず、ヘッダブロックの種別 `D3` が代わりになる。
- CSAVE の本体末尾には `00` を 7 バイト付ける。
- 行リンクは RAM アドレス。ロード時に ROM が再計算するため、絶対値の一致は必須ではない。

### 数値・参照の格納

| 値 | バイト列 |
| --- | --- |
| 0～9 | `0x11+n` |
| 10～255 | `0x0F, n` |
| 256～32767 | `0x1C, lo, hi` |
| 行番号（未変換） | `0x0E, lo, hi` |
| 行アドレス（RUN 後） | `0x0D, lo, hi` |
| 単精度 BCD | `0x1D` + 4 バイト |
| 倍精度 BCD | `0x1F` + 8 バイト |
| `&O` | `0x0B, lo, hi` |
| `&H` | `0x0C, lo, hi` |
| `&B` | ASCII のまま |

BCD は「符号 1 bit + 指数 7 bit（バイアス 64）+ BCD 仮数」。
値は `0.<仮数> × 10^(指数-64)`。単精度 6 桁、倍精度 14 桁。
0 は全体 0。負数は直前の `0xF2`（`-` トークン）で表し、BCD 自体は正。

例: `!123.456` → `1D 43 12 34 56`、`0.1`（既定の倍精度）→
`1F 40 10 00 00 00 00 00 00`。

有効桁数を超えた定数は、7 桁目（倍精度は 15 桁目）で丸めます。
例: `!12345678` → `1D 48 12 34 57`（12345700）。一部の資料にある
`0x1E` の 8 バイト定数は MSX の保存形式ではありません（MSX は `0x1F`）。

### 文字列・コメント・DATA

- 文字列は `"` で囲んだバイト列をそのまま格納。
- `REM` は `0x8F`、その後は行末まで無変換。
- `'` は `3A 8F E6`、その後は行末まで無変換。
- `DATA` は `0x84`、コロン（引用符の外）または行末まで無変換。CRUNCH と同様に
  DATA の内容（空白を含む）は保持し、引用符内のコロンは区切りにしない。
- `ELSE` は `3A A1`。逆変換では `3A A1` を `ELSE` として表示する。
- `?` は `PRINT`（`0x91`）。

## 2. CAS（BIOS 呼出しレベルのテープ像）

マーカー 8 バイト:

```
1F A6 DE BA CC 13 7D 74
```

CAS はこのマーカーをブロック先頭に置き、その後にブロックのバイト列を続けます。
実テープではマーカーはリーダー（無変調の連続音）に対応します。

| 種別 | ヘッダブロック | データブロック |
| --- | --- | --- |
| BASIC (CSAVE) | `D3`×10 + 名前 6 バイト | トークン化本体 + `00`×7 |
| バイナリ (BSAVE) | `D0`×10 + 名前 6 バイト | 開始 2 + 終了 2 + 実行 2 + コード |
| ASCII (SAVE/A) | `EA`×10 + 名前 6 バイト | 256 バイト単位（最後は `1A` で EOF） |

- 名前は 6 バイト。短ければ 0x20 で埋める。実装は超過をエラーにし、切り詰めない。
- BASIC はヘッダ（長リーダー）→本体（短リーダー）の 2 ブロック。
- ASCII はヘッダ→256 バイトブロック×N。最終ブロックは `1A` を含み、
  実装では 256 バイトまで `1A` で埋める。
- CAS のマーカーは 8 バイト境界。実装は各ブロックの後に 0x00 を追加して
  次のマーカーを 8 バイト境界に合わせる（最終ブロックも）。
- 実テープのリーダーは長 6.67 秒、短 1.67 秒。CAS には長短の区別がないため、
  ヘッダブロックは長、それ以外は短として生成する。

## 3. FSK フレーム

1 ビット:

- 1200 baud: `0` = 1200 Hz 1 周期、`1` = 2400 Hz 2 周期。1 ビット 40 サンプル。
- 2400 baud: `0` = 2400 Hz 1 周期、`1` = 4800 Hz 2 周期。1 ビット 20 サンプル。

1 バイト = 開始 0（1 ビット） + データ 8 ビット（LSB 先頭） + 停止 1（2 ビット）。
リーダーは 1 ビット（高音）の連続。長リーダーは 320,000 サンプル（6.667 秒）、
短は 80,000 サンプル（1.667 秒）。どちらも 1200/2400 で同じ時間。

生成器は各ビットを高位から始め、必ず低位で終えるため、ビット境界に必ずエッジが
できます。復調器はエッジ間隔だけを使うので、極性反転に影響されません。

## 4. 日本語 MSX 文字表

`core/src/charset.cpp` の表は openMSX `MSXVIDJP.TXT` に基づきます。

- `0x00-0x1F`: 制御コード（GRAPH 修飾は `0x01 + 0x41-0x5F`）
- `0x20-0x7E`: ASCII。ただし `0x5C` は `¥`
- `0x7F`: DEL
- `0x80-0x9F`: ♠♥♣♦○●、を、小書きひらがな、`0x90` 全角スペース、あ～そ
- `0xA0-0xDF`: 全角スペース、句読点、半角カナ、濁点・半濁点
- `0xE0-0xFD`: た～ん
- `0xFE-0xFF`: openMSX 表で未定義。私用領域でロスレス往復
- 濁点合成: `か+゛` → `が`、`は+゜` → `ぱ` など。書き出しは 2 バイトに分解。

CF-2000 の文字パレットと本表の一致、および MSX2+ とのひらがな差異は
実機（ED-01）で確認する必要があります。

## 5. WAV

- RIFF/WAVE、PCM（形式 1）、48,000 Hz、16 bit、モノラル/ステレオ。
- 外部入力は `fmt` チャンクを検証し、奇数長チャンクのパディングをスキップ。
- `data` が宣言より短い場合は警告して実長で復号。
- 44.1 kHz、8/24 bit、浮動小数点、圧縮形式はエラー。
- 出力はモノラル 44 バイトヘッダ。データは 2 GiB 弱で正常に打ち切り。
- 送信音量は生成時の振幅（1～100%、100% = 14745 ≈ -7 dBFS）で調整する。

## 6. WAV のピーク正規化（復号用コピー）

録音の原音WAVは仕様どおり無加工で保存する。正規化は**別ファイル**に対して行う。

- 目標ピーク: 既定 -6 dBFS（32767 × 10^(-6/20) ≈ 16423）
- 最大ゲイン: 既定 +12 dB。これを超える静かな録音は、目標まで上がらない旨を警告
- 16 bit PCM、入力と同じサンプルレート・チャンネル数
- 無音（ピーク 0）はエラー
- 2 パス（ピーク測定 → ゲイン適用）でストリーム処理
- サンプル値は丸め後に int16 の範囲へクランプ
- 原音を置き換えない。アプリでは `<名前>.normalized.wav`（既存なら `-1` などを付加）
